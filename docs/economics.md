# Экономика решения

> Раздел будет рассчитан на завершающем этапе проекта. Ниже — структура расчёта и исходные данные, которые для него нужны. Чисел здесь нет намеренно: в документ попадёт только то, что посчитано из названных источников.

## 1. Затраты

| статья | из чего складывается | источник данных |
|---|---|---|
| пилот в контуре заказчика | работы команды на подключение источников, настройку справочников и контрольных точек, приёмку сценариев | план пилота |
| развитие до промышленной версии | масштабирование, ГОСТ-профиль, PostgreSQL, подключение к живым 1С / Галактике / MES | план развития |
| сопровождение | разбор обращений, доработки, обновления версий анализаторов | договор сопровождения |
| оборудование сервиса | сервер ядра, хранилище журнала и материалов | замер ресурсов сервиса под нагрузкой (`reports/metrics/load.json`) |
| оборудование контроля | камеры, свет, вычислители на краю по [vision.md](vision.md) | коммерческие предложения поставщиков |
| лицензии | используемые библиотеки открыты; СКЗИ для ГОСТ-профиля — по выбору заказчика | перечень зависимостей в `pyproject.toml` |

## 2. Эффекты

| эффект | как измеряется | откуда базовый уровень |
|---|---|---|
| сокращение времени обнаружения | задержка обнаружения, [results.md](results.md) | замер до пилота |
| сокращение времени разбора | время от сигнала до решения | замер до пилота |
| снижение повторного брака | повторяющиеся причины после подтверждения | журнал несоответствий заказчика |
| снижение доработок | повторные обработки, прохождение с первого раза | учёт доработок заказчика |
| снижение ручного ввода | число переносимых руками записей между ОТК, MES и ERP | опрос и хронометраж |

## 3. Что нужно собрать

- стоимость одного несоответствия по видам: доработка, списание, задержка поставки;
- текущее время обнаружения и разбора;
- число изделий и контрольных точек на линии пилота;
- стоимость часа работы контролёра, мастера, технолога.
