Линии

Прогон по данным контракта

Параметры прогона задаются по контракту: число изделий, длительность показа, вероятности дефектов по этапам и принудительные дефекты для выбранных изделий. Ускорение рассчитывается автоматически. Новая линия создаётся в системе в блочном редакторе.

Импорт JSON-файла zd-flow/1

Для контракта, пришедшего файлом: линия и прогон одним документом (формат описан в docs/flows.md).
